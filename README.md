## Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/sakthyamoorthy/portfolio.git
cd portfolio
npm install
```

Run the app locally:

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Build for Production

```bash
npm run build
```

This bundles the app into the `build/` folder, optimized for production and ready to deploy.

## Deployment

This project is deployed on [Netlify](https://www.netlify.com/), connected to the `main` branch for continuous deployment.
